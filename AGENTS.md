# Maintaining this repository

Skills live in `<skill-name>/SKILL.md`, with supporting files beside them.

- Keep each skill focused on one kind of task, and keep its frontmatter
  `description` accurate.
- Keep relative links valid when moving or renaming files, and keep the README
  skill table in sync.
- Keep upstream `LICENSE` and `UPSTREAM.json` files unchanged. List new
  third-party material in `THIRD_PARTY_NOTICES.md`.
- Test what you change: run a changed script's tests and check changed commands
  and links.
- Do not commit credentials or private settings.
