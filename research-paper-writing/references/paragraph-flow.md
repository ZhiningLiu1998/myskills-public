# Checking Paragraph Flow

"Does this flow?" usually means one of three things: the reader cannot tell
what a paragraph is for, cannot see how it connects to the paper's main claim,
or cannot see how one sentence leads to the next. Check each separately.

## 1. Read as someone outside the project

The author already knows the missing steps, so gaps are hard to notice. Read
the section as a reviewer from a neighboring area would:

- Can the reader say what each paragraph is for after its first sentence?
- Is every key term defined before it is used, or is it a standard term in the
  field?
- Does each paragraph clearly support the section's main claim?

## 2. Reverse-outline the draft

Build an outline from the finished text rather than the plan:

1. Write the section's main claim in one sentence.
2. Under it, copy the first (topic) sentence of every paragraph.
3. Under each topic sentence, list the evidence or explanation the paragraph
   gives.
4. Check that each topic sentence supports the main claim and that each
   evidence point supports its topic sentence.
5. Rewrite, merge, move, or delete any paragraph that does not fit.

If the outline is hard to write, the section's main claim or its topic
sentences are probably unclear. Fix those before editing individual sentences.

## 3. Use temporary headings

When a full outline feels heavy, add a short heading above each paragraph or
group of paragraphs while revising. Headings that repeat, overlap, or appear in
an odd order show structural problems. Remove headings the final paper does not
need.

## 4. Make sentence relations explicit

Each sentence should relate to the previous one in a way the reader can name.
Use a connective when the relation would otherwise be unclear, and choose it by
meaning:

| Relation | Examples |
| --- | --- |
| Cause or consequence | because, therefore, as a result, thus |
| Contrast or exception | however, in contrast, although, instead |
| Addition or similarity | also, similarly, in addition |
| Example | for example, for instance, such as |
| Sequence | first, then, next, finally |
| Refinement or summary | specifically, in other words, in short |

A connective cannot repair a missing logical step. If no connective fits, the
sentence probably belongs elsewhere or a step is missing.
